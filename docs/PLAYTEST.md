# Phase 5 — first real playtest

Do not fix anything until you have watched one full session. Your job in the room is to
**watch**, not to explain.

## Setup

- 3–6 people, sitting together, one phone.
- Hand the phone over with no explanation beyond "it's a game, press play".
- Armenian is the default language. Switch to English from Settings if the group prefers it.
- The timer is chosen on the players screen: **2.5 / 3 / 3.5 seconds**. Leave it on the default
  **3 seconds** for the first game. If the group is up for more, play at least one round at
  each of 2.5, 3 and 3.5 seconds in the same session.

## What to write down

| Question | What to look for |
| --- | --- |
| Do people laugh? | During the countdown, or after the verdict? |
| Are the questions too easy? | Does anyone actually blurt the real answer? |
| Which questions land? | Note ids from the top of the screen — the boring ones get cut. |
| Is passing the phone annoying? | Watch the gap between turns. |
| Do they argue about PASS/FAIL? | If yes, the judging rule needs work. |
| Does the score matter? | Does anyone look at the results screen? |
| How long is one session? | Start to winner, in minutes. |
| Do they want another round? | An unprompted "again!" is the signal we are looking for. |

## The timer

Fill this in once per timer setting you tried.

| Question | What to look for |
| --- | --- |
| Which timer was used? | 2.5, 3 or 3.5 seconds. |
| Could they read and understand the question comfortably? | Watch for squinting, re-reading, or "wait, what?" |
| Did they have enough time to think? | Count how often the timer runs out with nothing said. |
| Did the round feel too slow? | Do people look away or start chatting before the timer ends? |
| Did the timer create useful pressure? | Panic answers are good; silence and shrugs are not. |
| Did anyone ask to change the timer? | Note what they asked for and when. |
| Which setting did the group prefer? | Only ask after they have tried more than one. |

## After the session

Send me: the timer verdict per setting and the group's favourite, the questions to cut, the
session length, and whether anyone asked for another round. That decides Phase 6.
