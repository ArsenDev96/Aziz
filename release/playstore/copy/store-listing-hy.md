
61 / 80 նիշ։

## Ամբողջական նկարագրություն

```
AZIZ-ը զվարճալի խաղերի հավաքածու է ընկերների համար, որ խաղում եք բոլորով՝ մեկ հեռախոսով։ Հեռախոսը փոխանցում եք իրար, ընտրում խաղը և սկսում՝ առանց գրանցման, առանց ինտերնետի, առանց երկար կարգավորումների։

Երեք խաղ՝ մեկ հավելվածում։

ՄԻԱՅՆ ՍԽԱԼ ՊԱՏԱՍԽԱՆ
Պարզ հարցեր, մեկ կանոն՝ ճիշտ պատասխանը չասես։ Ունես ընդամենը մի քանի վայրկյան, իսկ խումբը որոշում է՝ հաջողեցիր, թե ոչ։ Ավելի դժվար է, քան թվում է։

ՆՈՒՅՆ ՊԱՏԱՍԽԱՆԸ
Մեկ հարց՝ ամբողջ թիմին։ Բոլորը լուռ մտածում են մի պատասխան, հետո միասին բարձրաձայն ասում։ Ինչքան շատ եք համընկնում, այնքան շատ միավոր։

ՑՈՒՅՑ ՏՈՒՐ
Թիմերը հերթով են խաղում։ Մեկը գուշակում է, մնացածը բառը ցույց են տալիս՝ առանց խոսելու։ Ժամանակը սահմանափակ է, ուրեմն՝ արագ։

Օգտակար է իմանալ
• Ամբողջությամբ աշխատում է առանց ինտերնետի
• Գրանցում կամ հաշիվ պետք չէ
• Հայերեն և անգլերեն՝ ցանկացած պահի կարող եք փոխել
• Խաղացողների անունները մեկ անգամ եք գրում, դրանք մնում են ձեր հեռախոսում
• 2–8 խաղացող (թիմային խաղերի համար՝ առնվազն 4), կարճ ռաունդներ, կանոնները բացատրված են հավելվածում

Ընկերական հավաքույթների, ծննդյան օրերի, ճամփորդությունների և երկար երեկոների համար։
```
